The **Internal Payment Request System** is what staff in an organisation use to file payment requests. It can produce a PDF request form that's easy to print out. The system includes a database of payees, so the finance team can look up who gets paid and the bank details right away, which speeds up review and payment.

::: features
### Staff file requests
People inside the organisation can file a payment request directly in the system.

### PDF request form
A PDF request form can be generated, ready to print and hand in.

### Payee database
The system comes with a database of payees, recording who gets paid and their bank details.

### Faster review and payment
Finance staff can check the payee and bank details directly, which speeds up review and payment.
:::
